# scrap

tiny crumbles falling off the cake

Small, independent utilities that might be useful to someone else.

Each directory is self-contained. Read its own README for what it does, how it works, what privileges it needs, and how to remove it.

## Things currently here

- [TLP Charge Toggle](./tlp-charge-toggle/) — one GNOME Quick Settings button for switching between TLP's temporary full-charge mode and the charge thresholds already configured in TLP.
